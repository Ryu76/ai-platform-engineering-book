# 용어집

- **대규모 언어 모델(Large Language Model, LLM)**: 다음 토큰을 예측하는 생성 모델입니다.
- **검색 증강 생성(Retrieval-Augmented Generation, RAG)**: 외부 문서를 검색해 근거와 함께 답변하는 방식입니다.
- **모델 컨텍스트 프로토콜(Model Context Protocol, MCP)**: 모델·도구·리소스를 연결하는 프로토콜입니다.
- **라우터(Router)**: 요청·정책·상태에 따라 처리 경로를 선택하는 구성요소입니다.
- **토큰 사용량(Token Usage)**: 모델이 요청을 처리하며 소비한 입력 토큰과 생성한 출력 토큰의 수입니다.
- **비용 추정(Cost Estimate)**: 사용량과 명시한 가격표를 바탕으로 계산한 예상 금액이며, 제공자 청구 금액과 다를 수 있습니다.
- **지수 백오프(Exponential Backoff)**: 재시도 사이 대기 시간을 일정 배수로 늘려 일시적인 과부하를 완화하는 방식입니다.
- **대화 이력(Conversation History)**: 다음 모델 요청에 문맥으로 전달할 시스템·사용자·Assistant 메시지의 순서 있는 기록입니다.
- **턴(Turn)**: 사용자 메시지 하나와 그에 대응하는 Assistant 메시지 하나로 이루어진 대화 단위입니다.
- **토큰(Token)**: LLM이 텍스트를 처리할 때 사용하는 분할 단위입니다. 문자 수나 단어 수와 정확히 같지 않습니다.
- **토크나이저(Tokenizer)**: 텍스트를 모델이 처리하는 토큰으로 나누고 다시 텍스트로 해석하는 구성요소입니다.
- **컨텍스트 윈도우(Context Window)**: 한 요청에서 모델이 함께 처리할 수 있는 입력과 출력 토큰의 최대 범위입니다.
- **시스템 메시지(System Message)**: 대화의 역할, 범위, 제약을 먼저 전달하는 메시지입니다. 신뢰되지 않은 사용자 입력과 분리해야 합니다.
- **스트리밍(Streaming)**: 완성된 전체 응답을 기다리지 않고 생성 조각을 순서대로 받는 응답 방식입니다.
- **환각(Hallucination)**: 모델이 근거가 부족하거나 틀린 내용을 그럴듯하게 생성하는 현상입니다.
