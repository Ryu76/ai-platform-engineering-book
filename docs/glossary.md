# 용어집

- **대규모 언어 모델(Large Language Model, LLM)**: 다음 토큰을 예측하는 생성 모델입니다.
- **검색 증강 생성(Retrieval-Augmented Generation, RAG)**: 외부 문서를 검색해 근거와 함께 답변하는 방식입니다.
- **모델 컨텍스트 프로토콜(Model Context Protocol, MCP)**: 모델·도구·리소스를 연결하는 프로토콜입니다.
- **라우터(Router)**: 요청·정책·상태에 따라 처리 경로를 선택하는 구성요소입니다.
- **토큰 사용량(Token Usage)**: 모델이 요청을 처리하며 소비한 입력 토큰과 생성한 출력 토큰의 수입니다.
- **비용 추정(Cost Estimate)**: 사용량과 명시한 가격표를 바탕으로 계산한 예상 금액이며, 제공자 청구 금액과 다를 수 있습니다.
- **지수 백오프(Exponential Backoff)**: 재시도 사이 대기 시간을 일정 배수로 늘려 일시적인 과부하를 완화하는 방식입니다.
