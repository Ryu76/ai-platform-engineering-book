# LLM 기초: 학습 목표

## 1. 학습 목표

이 Volume을 끝내면 다음을 할 수 있어야 합니다.

- 생성형 AI와 대규모 언어 모델(Large Language Model, LLM)의 역할을 구분한다.
- 토큰(Token), 컨텍스트 윈도우(Context Window), 입력·출력 토큰의 관계를 설명한다.
- System, User, Assistant 메시지를 목적에 맞게 구성한다.
- Temperature, Top-p, 최대 출력 토큰을 조절하고 결과 차이를 해석한다.
- 환경 변수로 API 키를 관리하는 Python 클라이언트를 작성한다.
- Streaming, Timeout, HTTP 오류를 안전하게 처리한다.
- Mock 테스트로 키 없이도 클라이언트 동작을 검증한다.

## 2. 완료 기준

- [ ] `.env`와 `.env.example`의 차이를 설명할 수 있다.
- [ ] 실제 API 키를 Git에 넣지 않았다.
- [ ] MockTransport 테스트가 통과한다.
- [ ] 라이브 호출은 사용자가 키를 설정한 경우에만 수행한다.
- [ ] 실패 응답에서 API 키가 로그나 예외 메시지에 나타나지 않는다.
